# LegacyLink – SOIT Alumni Network

LegacyLink is a MERN Stack alumni networking platform developed for **SOIT, RGPV Bhopal**. It connects students, alumni, faculty members, and administrators.

## Main Features

* User authentication
* Alumni search
* Mentorship system
* Real-time messaging
* Events management
* Jobs and internships
* Admin dashboard

## Tech Stack

**Frontend:** React.js, HTML, CSS, JavaScript
**Backend:** Node.js, Express.js, JWT, Socket.io
**Database:** MongoDB, Mongoose

## Project Setup

```bash
git clone your-repository-link
cd LegacyLink
npm install
npm run dev
```
